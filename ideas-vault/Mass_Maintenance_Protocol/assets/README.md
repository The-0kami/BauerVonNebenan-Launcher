# Geplante MMP-Assets – noch keine Binärdateien

Die Dateien dieses Ordners dienen vorerst nur als **Platzhalter für spätere Archivstruktur**, nicht als Beleg archivierter Medien.

Bei Wiederaufnahme und nach Rechteprüfung sind denkbar:

```
assets/
  music/originals/     # unbearbeitete Stereomaster und Extend-Varianten
  music/stems/         # tatsächlich vorhandene Export-Stems
  music/edits/         # kontrollierte Restaurationen / Segmentversionen
  visuals/             # finale, freigegebene Warn-/Dialoggrafiken
  licenses/            # Quellen, Freigaben und Nutzungsbedingungen
```

Die konkreten Originaldateien liegen nach bisherigem Kenntnisstand **nicht in diesem GitHub-Vault**. Sie müssen vom lokalen Codex-/Suno-Arbeitsstand übernommen und vor einer Veröffentlichung rechtlich geprüft werden. Siehe [ASSET_MANIFEST.md](../ASSET_MANIFEST.md).
